# Gestor de Tareas - CRUD en C#

Aplicación de consola desarrollada en C#. La aplicación es un CRUD que sirve para la gestión de tareas.

## Funcionalidades

- **Crear tarea**: registrar una nueva tarea con título y descripción.
- **Ver todas las tareas**: listar todas las tareas registradas.
- **Buscar tarea por Id**: consultar una tarea específica.
- **Actualizar tarea**: modificar título, descripción y estado de una tarea existente.
- **Eliminar tarea**: borrar una tarea del sistema.

## Tecnologías

- C#
- .NET 10
- Aplicación de consola
